Clauses des contrats

Modifiez ici les phrases des contrats. Le nouveau texte est utilisé pour tous les contrats affichés, imprimés ou téléchargés ensuite, y compris pour les conducteurs déjà inscrits. Les zones de signature restent identiques.

Comment écrire le texte ? Champs automatiques

Une ligne = un paragraphe. # Titre pour le titre, ## Article… pour un intertitre, >> Fait à… pour la ligne « Fait à… », **mot** pour du gras. Cliquez sur un champ pour l’insérer à l’endroit du curseur : il sera remplacé par l’information du conducteur (des pointillés s’il n’est pas renseigné).
